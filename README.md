# Luke Chamandy — GitHub Pages website

This is a simple academic personal website designed for GitHub Pages.

## Files

- `index.html` — homepage
- `style.css` — site styling
- `cv.html` — CV page
- `teaching.html` — teaching page
- `Luke_Chamandy_CV.pdf` — add your PDF CV here

## Publish

Create a repository named:

`YOUR-GITHUB-USERNAME.github.io`

Upload these files, then go to:

Settings → Pages → Deploy from a branch → `main` → `/ (root)`

The site will be available at:

`https://YOUR-GITHUB-USERNAME.github.io`

## Before publishing

Replace the placeholder ADS and Zenodo links with the exact links to your publications and software. Add your PDF CV as `Luke_Chamandy_CV.pdf`.
